# risshisha-java

Java 言語


起源

=>1995年　Sun Microsystems 
=>当初　‘Oak’
=>特徴　→ Write Once, Run Anywhere
=>Java仮想マシン　JVM
=>どのプラットフォーム上でも変更なしに動作できる

特徴

=>基本的にコンパイラでソースコードをコンパイルしてから実行
→Javaのコンパイラは、Java仮想マシン（JVM）の上でプログラムが実行できるようにするよう、ソースコードをバイトコードと呼ばれる中間言語に変換するのです。

=>JVMが存在する環境なら機種やOSの違いなどによらず同じように動作させることができるという点
